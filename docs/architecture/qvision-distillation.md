# Q Vision: moved to Qore Catalog

Q Vision training and product images moved to **Qore Catalog**, a separate product. Qore Catalog owns the canonical images and the recognition training samples for each product.

Tally's part:

- **Contributes** confirmed shelf crops to Qore Catalog (`POST /v1/images`). See [product crops](vision-recognition.md#product-crops).
- **Uses** what Qore Catalog provides later, such as visual match signals and models.
